# نظام إدارة معدات تكنولوجيا المعلومات (IT Equipment Management System) - C++ OOP

## نظرة عامة على المشروع

هذا المشروع هو تطبيق سطر أوامر (Console Application) بلغة C++، مصمم لإدارة معدات تكنولوجيا المعلومات باستخدام مفاهيم البرمجة كائنية التوجه (Object-Oriented Programming - OOP). يهدف المشروع إلى توضيح كيفية تصميم وتنفيذ نظام لإدارة الأصول الرقمية، مع التركيز على تتبع الأجهزة، تحديث حالاتها، وتوليد تقارير الصيانة.

تم تطوير هذا النظام ليكون مثالاً عملياً لطلاب تكنولوجيا المعلومات في السنة الثانية، حيث يغطي جوانب أساسية في تصميم البرمجيات وهيكلة البيانات باستخدام C++.

## الميزات الرئيسية

يتضمن النظام الميزات التالية:

*   **إدارة الأجهزة**: إضافة، تحديث، وحذف أنواع مختلفة من أجهزة تكنولوجيا المعلومات.
*   **تتبع حالة الجهاز**: القدرة على تحديث حالة الجهاز (نشط، معطل، تحت الصيانة).
*   **عرض معلومات الأجهزة**: عرض تفاصيل جميع الأجهزة المسجلة أو جهاز معين بناءً على رقمه التسلسلي.
*   **تقارير الصيانة**: توليد تقارير صيانة مخصصة لكل نوع من الأجهزة.
*   **واجهة مستخدم تفاعلية**: قائمة بسيطة تعتمد على سطر الأوامر للتفاعل مع النظام.

## مفاهيم البرمجة كائنية التوجه (OOP) المطبقة

يُظهر هذا المشروع تطبيقًا عمليًا للمفاهيم الأساسية للبرمجة كائنية التوجه:

*   **التغليف (Encapsulation)**: يتم حماية خصائص الأجهزة (مثل الرقم التسلسلي، النوع، الحالة) داخل الفئات، ويتم الوصول إليها وتعديلها فقط من خلال دوال الوصول (Getters) ودوال التعديل (Setters).
*   **الوراثة (Inheritance)**: توجد فئة أساسية `Device`، وتُشتق منها فئات متخصصة مثل `Computer`، `Printer`، و `Router`. ترث هذه الفئات المشتقة الخصائص والسلوكيات العامة من الفئة الأساسية وتضيف خصائصها وسلوكياتها الفريدة.
*   **تعدد الأشكال (Polymorphism)**: يتم استخدام الدوال الافتراضية (Virtual Functions) مثل `displayInfo()` و `generateMaintenanceReport()` في الفئة الأساسية `Device`. هذا يسمح باستدعاء التنفيذ الصحيح للدالة بناءً على النوع الفعلي للكائن وقت التشغيل، مما يتيح معالجة أنواع مختلفة من الأجهزة بطريقة موحدة.

## التقنيات المستخدمة

*   **C++11/14/17**: لغة البرمجة الأساسية.
*   **Standard Template Library (STL)**: لاستخدام هياكل البيانات مثل `std::vector` و `std::string`.
*   **Smart Pointers (`std::unique_ptr`)**: لإدارة الذاكرة بشكل آمن وفعال، وتجنب تسرب الذاكرة (Memory Leaks).

## المهارات المكتسبة من هذا المشروع

من خلال تطوير هذا المشروع، سيكتسب الطالب المهارات التالية:

*   **تصميم الفئات والكائنات**: كيفية تصميم فئات تمثل كيانات حقيقية وعلاقاتها ببعضها البعض.
*   **تطبيق مبادئ OOP**: فهم وتطبيق التغليف، الوراثة، وتعدد الأشكال في مشروع عملي.
*   **إدارة الذاكرة في C++**: استخدام المؤشرات الذكية (`std::unique_ptr`) لإدارة دورة حياة الكائنات والذاكرة.
*   **التعامل مع الإدخال/الإخراج**: قراءة المدخلات من المستخدم وعرض المخرجات على سطر الأوامر.
*   **هيكلة المشروع**: تنظيم الكود في ملفات رأسية (.h) وملفات مصدرية (.cpp) لسهولة الإدارة والصيانة.
*   **تصميم واجهة المستخدم النصية**: بناء واجهة تفاعلية بسيطة تعتمد على القوائم لسهولة الاستخدام.

## كيفية تجميع وتشغيل المشروع

لتجميع وتشغيل هذا المشروع، ستحتاج إلى مترجم C++ (مثل g++). اتبع الخطوات التالية:

1.  **استنساخ المستودع (Clone the repository)**:
    ```bash
    git clone https://github.com/your-username/it-equipment-management-cpp.git
    ```
    (ملاحظة: ستحتاج إلى استبدال `your-username` باسم المستخدم الخاص بك على GitHub بعد رفع المشروع.)

2.  **الانتقال إلى مجلد المشروع**:
    ```bash
    cd it-equipment-management-cpp
    ```

3.  **التجميع (Compile)**:
    استخدم الأمر التالي لتجميع جميع الملفات المصدرية:
    ```bash
    g++ src/*.cpp -o it_equipment_manager -std=c++17
    ```
    *   `g++`: هو المترجم (Compiler).
    *   `src/*.cpp`: يحدد جميع ملفات `.cpp` داخل مجلد `src` للتجميع.
    *   `-o it_equipment_manager`: يحدد اسم الملف التنفيذي الناتج (Executable).
    *   `-std=c++17`: يحدد معيار C++ المستخدم (يمكنك استخدام `c++11` أو `c++14` إذا كان المترجم لا يدعم `c++17`).

4.  **التشغيل (Run)**:
    بعد التجميع بنجاح، يمكنك تشغيل التطبيق باستخدام الأمر:
    ```bash
    ./it_equipment_manager
    ```
